# Хранители Льва: Капани

Неофициальная русскоязычная визуальная новелла о внезапном переносе пятёрки Хранителей в вымышленный абсурдистский двор. История содержит пролог, шесть глав, ветвящиеся решения и четыре варианта финала. Исходный текст задания сохранён без изменений в `lore/source-spec.txt`.

## Запуск

Нужен Python 3.10+; зависимости не требуются. Из корня проекта:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Сохранения и три ручных слота используют localStorage браузера. Для запуска новой смены нажмите «Новая игра». Пробел, Enter или кнопка со стрелкой продвигают диалог. Параметры доступны в меню настроек.

## Что внутри

- `index.html` — меню и игровая сцена.
- `styles.css` — адаптивный интерфейс, сцена и персонажи.
- `game.js` — игровые данные, реплики, выборы, состояния, сохранения и финалы.
- `assets/courtyard.png` — сгенерированный фон двора.
- `assets/heroes/` — пять оригинальных SVG-иллюстраций животных для сцен Хранителей.
- `lore/source-spec.txt` — исходное задание целиком.

Выборы меняют доверие санитаров, хаос двора, сплочённость команды и осведомлённость. Эти показатели отражаются в сводке, маршруте и итоговом протоколе. Диалоги, журнал, главы, настройки, автопролистывание, пропуск, скрытие интерфейса и сохранение доступны в UI.

## Ограничения текущей версии

Интернет-поиск по официальным страницам Disney и D23 в облачной среде получил 403 от сетевого прокси, поэтому канонические характеры сверены с контрольными описаниями в задании. В проекте нет официальных изображений персонажей. Пять оригинальных векторных рисунков животных используются как приблизительные игровые образы, а не как точные канонические спрайты. Генератор изображений отклонил запросы на набор зверей, поэтому эти SVG нарисованы вручную и отличаются от стиля сериала. Один сгенерированный фон включён в игру. Остальные локации используют его с цветовыми вариантами; отдельные CG, музыка и полный набор спрайтов жителей требуют лицензированных ассетов или допустимых референсов.

Интерфейс и вымышленные происшествия не являются медицинским описанием. Игра неофициальная и не связана с Disney.
